            在庫（製品・部品）が 1 か月以内または半年以内に不足する見込みになると、下の送信先へメールします。
            同じ品目・部品への通知は「初回 → 30 日後 → 180 日後」の最大 3 回で、在庫が増えるとリセットされます。
            在庫が未登録の品目・部品は通知しません。

送信元メール（SMTP）

        

          Gmail を使う場合 — アプリパスワードの取得手順
          

            前提: Google アカウントで 2 段階認証が有効になっていること

            1. myaccount.google.com/security を開く

            2. 「2 段階認証プロセス」→「アプリパスワード」を開く

            3. アプリ名に「Manuphet」など任意の名前を入力して作成

            4. 表示された 16 文字のパスワード（スペース不要）を下の「パスワード」欄に貼り付ける

            設定値: SMTP サーバー smtp.gmail.com / ポート 587
